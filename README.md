# Christian Lufulwabo Portfolio

Three-page portfolio website created in Figma and converted into HTML, CSS, and Bootstrap.

## Pages

- `index.html` - Home
- `about.html` - About
- `contact.html` - Contact

## Project structure

```text
.
├── index.html
├── about.html
├── contact.html
├── css/
│   ├── styles.css
│   ├── styles2.css
│   ├── styles3.css
│   └── vars.css
├── images/
│   └── christian-lufulwabo.png
└── js/
    └── script.js
```

## Run locally

Open the folder in VS Code and use the Live Server extension to launch `index.html`.

The navigation links use relative HTML paths, so the same files can be deployed directly to GitHub Pages or Netlify.
